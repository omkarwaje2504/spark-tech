# Sparktech Website Explanation Guide

## 1. What the website is meant to do

This website is not only a company brochure. Its main job is to help a new visitor understand three things quickly:

1. What Sparktech does.
2. Why Sparktech is credible.
3. What action the visitor should take next.

For a new user, the website should reduce confusion and move them from curiosity to trust, and from trust to enquiry.

---

## 2. New user point of view

Most first-time visitors to this website are likely to think in a very practical way:

- "What exactly does this company make or deliver?"
- "Can they handle my type of plant or project?"
- "Why should I trust them over another supplier?"
- "Can I contact them easily without wasting time?"

The current website structure is designed to answer those questions in a sequence.

## 4. Meaning of each homepage section in simple client language

### Header
The header is the control center of the website. It tells the visitor where they are, what pages are available, and how to contact Sparktech immediately.

### Hero
The hero section is the first and most important sales message. It tells a new user that Sparktech is an EPC partner for edible oil plants, not just a machine seller.

### About
This section answers the question: "Why should I trust this company?" It focuses on differentiation, process-first engineering, global exposure, and support after commissioning.

### Services
This section explains what Sparktech actually offers. It is designed to surface the main commercial categories first, then give access to the wider service range.

### Process Flow
This section explains how a project moves from discussion to execution. It makes the company feel organized, accountable, and easier to work with.

### Quick Inquiry
This is the lead-capture section placed in the middle of the homepage. It is important because many users decide to contact a company before reaching the bottom of the page.

### Gallery
This section provides visual proof and international references. It tells the visitor that Sparktech has delivered work in multiple countries and project types.

### CTA
This is the final push for conversion. It is built for users who now understand the offer and just need a clear next step.

### Footer
The footer supports both trust and usability. New users often scroll to the bottom to confirm company details, contact information, and legitimacy.

## 6. Exact user flow

### Flow A: New user landing on the homepage

1. User lands on homepage.
2. User reads the hero and understands Sparktech is an edible oil EPC partner.
3. User scans the About section to understand why the company is credible.
4. User checks Services to see whether Sparktech covers their need.
5. User looks at Process Flow to understand how the project will be handled.
6. User checks Gallery for proof and references.
7. User submits Quick Inquiry or clicks the final CTA.

Why this flow works:
It moves the user from clarity -> trust -> fit -> proof -> action.

### Flow B: User coming from search directly to a service page

1. User lands on a service detail page.
2. User reads technical content for that specific solution.
3. User sees applications, related services, and quote CTA.
4. When the user later opens the contact form, the service field can be pre-filled based on the visited service.

Why this flow works:
It respects the intent of users who already know what process or plant type they are researching.

### Flow C: High-intent user ready to contact quickly

1. User sees header CTA, sticky CTA, or hero CTA.
2. User clicks through to Contact or calls directly.
3. User completes form or uses phone/email option.

Why this flow works:
It does not force a ready buyer to read the whole website before taking action.

## 8. Important UX and functionality notes

### Service interest memory
If a user visits a service detail page first, the site stores that service interest in a cookie and uses it to prefill the service field in the enquiry form later.

Business value:
This reduces effort for the user and keeps the enquiry more accurate.

### Hidden service pages
`deodorization` and `bleaching` pages currently exist, but they are filtered out from some primary service lists and menus.

Business value:
This keeps the visible offer simpler and avoids overloading the first-time user with too many choices.

### Contact form behavior
The form currently shows a success state in the UI after a simulated delay.

Important note:
If this guide is being shared internally, the form still needs a real backend or email integration for live lead handling.

The website is designed to guide a new industrial buyer from first impression to enquiry. Each section has a specific role: the hero explains what Sparktech does, the about section builds trust, the services section shows fit, the process section reduces uncertainty, the gallery provides proof, and the enquiry sections convert interest into action. From a new user perspective, the website is meant to answer "What do you do?", "Why should I trust you?", "Can you solve my requirement?", and "How do I contact you?" in a clear sequence.
